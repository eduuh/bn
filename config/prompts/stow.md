1. Read the assigned task and active plan; identify what actually completed or remains open.
2. Load `workspan skills render stow-workflow` and follow it. Update actionable task/plan state
   and reusable references; Entire owns captured session history.
3. Record only verified, non-duplicative findings on the existing task/provider or in references.
   Preserve secrets and unfinished work; do not create parallel memory files, serialized handoff
   packets, or entries for routine URLs.
4. Report what was recorded and what remains. Never mark incomplete work done.
