Form controls

Input, textarea, label, select. All sit on bg-background — a well cut into the card, not a raised surface — and edge with border-input, which is lighter than chrome borders on purpose so an interactive field reads as interactive.

The composer pre-fills this from the row you started from.

States

There is no error state in the kit — writes surface failures through the toast stack instead. Whether a field-level error is owed is an open question for this round.
