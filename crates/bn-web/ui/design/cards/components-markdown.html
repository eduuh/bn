Markdown prose

Branch notes, handoff packets and agent plans all render through one class block — MARKDOWN_PROSE, a hand-rolled stand-in for the typography plugin, which cannot be used while preflight is off. Agent output is mostly commands and diffs, so pre and code carry more weight here than in ordinary prose.

Console shell

Replaces the ranked action list with a three-column layout that resolves a selection without navigating. Selection lives in ?sel= so it survives a reload and can be linked.

What changed

  • Queue · Focus · Act, with the act column folding under the focus pane below xl.
  • Rows resolve a verb per item — a plan review offers "decide", not "start another agent".
  • Row height drops to ~52px so nineteen items fit where six did.

Verify
