Terminal

The live xterm pane — the one surface whose colours are not tokens. Its palette is hard-coded hex in lib/term.ts, because xterm cannot read CSS variables. That makes it the surface most likely to be left behind by a reskin, so it is pinned here where the drift is visible.

ANSI ramp

black red green yellow blue magenta cyan white
br.black br.red br.green br.yellow br.blue br.magenta br.cyan br.white

Sixteen ANSI slots plus background, foreground, cursor and selection — twenty values that must be re-derived by hand for any palette change, and the reason a mono-hex mirror needs a comment pointing at whichever file is actually authoritative.
